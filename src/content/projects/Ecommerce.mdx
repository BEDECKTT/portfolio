#  Sistema E-commerce + Gestión de Tiendas Físicas

Este proyecto es una plataforma híbrida de **e-commerce y gestión de ventas para tiendas físicas**, diseñada para centralizar el control de productos, ventas, pagos y administración del negocio en un solo sistema.

---

##  Descripción

El sistema permite:

-  Gestión de productos para tienda en línea y física
-  Control de ventas en tiempo real
-  Procesamiento de pagos mediante PayPal
-  Administración de inventario
-  Manejo de clientes y pedidos
-  Soporte para operaciones en tiendas físicas (POS básico)
-  Gestión de imágenes en la nube

---

##  Tecnologías Utilizadas

### Frontend / Fullstack
- Next.js
- TypeScript
- React (incluido en Next.js)

### Backend / Base de Datos
- SQL Server
- API Routes de Next.js

### Servicios Externos
- Cloudinary (gestión y almacenamiento de imágenes)
- PayPal API (procesamiento de pagos)

---

## ⚙️ Funcionalidades Principales

###  E-commerce
- Catálogo de productos
- Carrito de compras
- Checkout con PayPal
- Gestión de pedidos

###  Tienda Física
- Registro de ventas manuales
- Control de inventario en tiempo real
- Registro de clientes
- Cierre de ventas por turno

###  Administración
- CRUD de productos
- Gestión de stock
- Reportes de ventas
- Control de usuarios (administradores y vendedores)

---

##  Base de Datos

El sistema está basado en **SQL Server**, manejando entidades como:

- Productos
- Ventas
- Detalles de venta
- Clientes
- Usuarios
- Inventario

---

##  Integraciones

###  Cloudinary
Se utiliza para:
- Subida de imágenes de productos
- Optimización y almacenamiento en la nube

###  PayPal
- Procesamiento de pagos en línea
- Confirmación de transacciones
- Registro automático de ventas pagadas
