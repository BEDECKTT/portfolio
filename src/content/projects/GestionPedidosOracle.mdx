# Sistema de Gestión de Pedidos

## Descripción General

Sistema de gestión desarrollado sobre **Oracle Database** para administrar productos, pedidos y clientes, manteniendo la información organizada, relacionada y disponible para las operaciones del negocio.

## Funcionalidades

- Gestión de productos, clientes y pedidos.
- Registro y consulta de detalles asociados a cada pedido.
- Control de los movimientos de información entre las entidades del sistema.
- Automatización de operaciones mediante lógica almacenada en la base de datos.

## Desarrollo de Base de Datos

- Implementación de procedimientos almacenados, funciones y triggers.
- Diseño de consultas SQL para controlar productos, clientes, pedidos y detalles de pedidos.
- Aplicación de buenas prácticas de normalización y diseño relacional.
- Optimización de consultas para mejorar el acceso a la información.
- Reglas de integridad para mantener la consistencia de los datos.

## Tecnologías Utilizadas

- Oracle Database
- SQL
- PL/SQL
- Procedimientos almacenados
- Funciones
- Triggers
