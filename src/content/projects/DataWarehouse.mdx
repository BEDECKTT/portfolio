# Data Warehouse Empresarial

## Descripción General

Este proyecto consiste en la construcción de un **Data Warehouse empresarial** para centralizar información procedente de múltiples fuentes de datos, incluyendo bases de datos **Oracle Database** y **SQL Server**.

La solución fue diseñada para convertir datos operativos en información confiable y útil para el análisis financiero, comercial y operativo de la organización.

## Trabajo Realizado

- Diseño de procesos de extracción, transformación y carga de datos.
- Limpieza, validación, transformación e integración de información mediante **SQL Server Integration Services (SSIS)**.
- Creación de modelos dimensionales con esquemas estrella, tablas de hechos, dimensiones, claves sustitutas y medidas de negocio.
- Desarrollo de modelos analíticos, indicadores y métricas con **SQL Server Analysis Services (SSAS)**.
- Configuración de relaciones, medidas y cálculos para facilitar el análisis empresarial.
- Optimización de consultas analíticas y procesos de carga para mejorar el rendimiento y la disponibilidad de la información.

## Visualización de Datos

Se desarrollaron dashboards e informes interactivos en **Microsoft Power BI** para presentar:

- Indicadores clave de rendimiento.
- Tendencias y comparaciones.
- Resultados financieros, comerciales y operativos.
- Información relevante para apoyar la toma de decisiones.

## Tecnologías Utilizadas

- SQL Server
- Oracle Database
- SQL Server Integration Services (SSIS)
- SQL Server Analysis Services (SSAS)
- Microsoft Power BI
- Modelado dimensional y procesos ETL
