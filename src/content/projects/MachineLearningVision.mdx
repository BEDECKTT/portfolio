# Proyectos de Machine Learning y Visión Artificial

## Descripción General

Colección de proyectos desarrollados en **Python** que aplican técnicas de aprendizaje supervisado, aprendizaje no supervisado y visión artificial para resolver problemas de clasificación y reconocimiento de imágenes.

## Machine Learning

- Implementación de modelos de clasificación con **regresión logística**, **árboles de decisión** y **Support Vector Machines (SVM)**.
- Aplicación de técnicas de aprendizaje no supervisado con **K-Means**.
- Reducción de dimensionalidad mediante **Principal Component Analysis (PCA)**.
- Preparación de datos, entrenamiento de modelos, evaluación de métricas y análisis de resultados.

## Visión Artificial

- Desarrollo de clasificadores de imágenes con redes neuronales convolucionales.
- Clasificación de conjuntos de datos de perros y gatos, flores, frutas y dígitos manuscritos.
- Uso de modelos preentrenados de detección de objetos.
- Reconocimiento de personas, teléfonos, botellas, sillas, computadoras y otros objetos en imágenes y video.

## Tecnologías Utilizadas

- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Redes neuronales convolucionales
- Google Colab
- Kaggle
