# Análisis de Factores Asociados a la Depresión y la Salud Mental

## Descripción General

Este proyecto tiene como objetivo identificar y analizar los factores sociodemográficos, hábitos de vida y antecedentes médicos que presentan una posible relación con los niveles de depresión y salud mental en la población estudiada.

Mediante técnicas de procesamiento y análisis de datos a gran escala, se exploraron patrones y tendencias que permiten comprender mejor las variables que influyen en el bienestar psicológico de los individuos. El estudio se enfoca en variables como edad, género, nivel educativo, situación laboral, hábitos de sueño, actividad física, consumo de sustancias y antecedentes clínicos.

La solución fue desarrollada utilizando tecnologías de Big Data para procesar grandes volúmenes de información de manera eficiente, permitiendo la obtención de métricas descriptivas, consultas analíticas y visualizaciones orientadas a la toma de decisiones basada en datos.

## Objetivos del Proyecto

- Analizar la relación entre factores demográficos y los niveles de depresión.
- Identificar patrones de comportamiento asociados a la salud mental.
- Evaluar el impacto de hábitos de vida en el bienestar psicológico.
- Generar indicadores que faciliten la interpretación de los datos.
- Aplicar técnicas de procesamiento distribuido para el análisis de grandes conjuntos de datos.

## Tecnologías Utilizadas

### Lenguaje de Programación
- Scala

### Framework de Procesamiento de Datos
- Apache Spark  
  - Spark SQL para consultas estructuradas.
  - Procesamiento distribuido de grandes volúmenes de información.
  - Transformación y análisis de datos en memoria.

### Plataforma de Desarrollo
- Databricks  
  - Entorno colaborativo basado en la nube.
  - Integración nativa con Apache Spark.
  - Ejecución de notebooks para análisis exploratorio y procesamiento de datos.

### Formato de Datos
- CSV (Comma-Separated Values)

## Metodología

1. Recolección y carga de datos.
2. Limpieza y preparación de la información.
3. Transformación de variables mediante Apache Spark.
4. Análisis exploratorio de datos (EDA).
5. Generación de consultas analíticas utilizando Spark SQL.
6. Interpretación de resultados y extracción de conclusiones.

El proyecto permite identificar tendencias y correlaciones relevantes relacionadas con la depresión y la salud mental, proporcionando información útil para futuras investigaciones, análisis predictivos y estrategias orientadas al bienestar psicológico.
