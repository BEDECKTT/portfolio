# Agente Académico de Inteligencia Artificial

## Descripción General

Este proyecto es un agente académico desarrollado con **Python** y **Streamlit**, orientado a responder consultas relacionadas con programación, tecnología e inteligencia artificial mediante modelos de lenguaje ejecutados localmente.

## Características Principales

- Integración con **LM Studio** para ejecutar modelos de lenguaje de manera local.
- Comunicación con el servidor local mediante una API compatible con OpenAI.
- Detección automática de los modelos disponibles a través de los endpoints proporcionados por LM Studio.
- Instrucciones de sistema para controlar el comportamiento, el formato de las respuestas y el dominio de conocimiento del asistente.
- Manejo de solicitudes HTTP, errores y tiempos de espera.
- Generación de respuestas directamente desde modelos locales.

## Interfaz

Se desarrolló una interfaz interactiva en **Streamlit** para facilitar la comunicación entre el usuario y el modelo de lenguaje, ofreciendo una experiencia sencilla para realizar consultas académicas.

## Tecnologías Utilizadas

- Python
- Streamlit
- LM Studio
- Requests
- API compatible con OpenAI
- Modelos de lenguaje locales
